# int_design

Portfolio bilingue (FR/EN) d’un atelier d’architecture intérieure, extérieure et paysagère basé à Lomé.

## Expérience

- Navigation et contenu éditorial pour l’atelier, la galerie, le journal et l’équipe
- Parcours FR/EN avec détection de langue, préférence persistante et routes dédiées `/en/*`
- Animations respectueuses de `prefers-reduced-motion`, avec GSAP et Anime.js
- Galerie filtrable, fiches projets, lightbox et prise de rendez-vous par e-mail
- SEO : métadonnées, JSON-LD, Open Graph, Twitter Card, `hreflang` et sitemap multilingue

## Démarrer

```bash
npm run dev
```

## Vérifier

```bash
npm run typecheck
npm run build
```

## Stack

React 19 · TanStack Start · TypeScript · Tailwind CSS v4 · GSAP · Anime.js
